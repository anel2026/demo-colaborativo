# Nombre del proyecto

**demo-colaborativo**

# Descripción

Página web básica hecha con HTML. Muestra un título, un párrafo y un pie de página. No tiene estilos, scripts ni otras funciones.

# Objetivo

Servir como ejemplo sencillo de una página HTML para aprendizaje.

El texto de la página indica que el proyecto sirve para practicar el trabajo en equipo.

# Archivos que contiene

- `index.html`: página principal. Incluye el título "Mi primer proyecto colaborativo", un párrafo y el pie de página "Proyecto de aprendizaje".
- `README.md`: documentación del proyecto.

# Tecnologías utilizadas

- HTML

# Cómo abrir y ejecutar el proyecto

1. Abre la carpeta `demo-colaborativo`.
2. Abre el archivo `index.html` en el navegador.

No hace falta instalar dependencias ni usar un servidor.
